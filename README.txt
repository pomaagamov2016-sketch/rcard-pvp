RCARD PvP ONLINE — АККАУНТЫ, ОБЛАЧНОЕ СОХРАНЕНИЕ И СЕТЕВОЙ PvP

Что входит:
- регистрация и вход по имени игрока и паролю;
- пароль хранится как криптографический хеш (scrypt), не в открытом виде;
- облачное сохранение валюты, инвентаря, экипировки, профиля, почты и погоды;
- поиск соперника в реальном времени через Socket.IO;
- пошаговый онлайн-дуэльный режим с HP, ходами, уроном, рейтингом и таблицей лидеров;
- исходная браузерная игра и фоновые изображения.

ЗАПУСК ЛОКАЛЬНО:
1. Установи Node.js 18 или новее.
2. Открой терминал в этой папке.
3. Выполни: npm install
4. Выполни: npm start
5. Открой http://localhost:3000

ПУБЛИКАЦИЯ В ИНТЕРНЕТЕ:
Нужен хостинг Node.js, поддерживающий WebSocket и постоянный диск/volume (например, Render, Railway или VPS). Загрузи всю папку проекта, установи зависимости командой npm install и запускай npm start. Укажи переменную окружения RCARD_SECRET со случайным длинным секретом. Для сохранения аккаунтов между перезапусками подключи постоянный диск и задай RCARD_DB на путь к файлу data.json на этом диске. Используй HTTPS. Статический Netlify Drop не запускает server.js и не обеспечивает эти функции.

ВАЖНО:
- Игроки смогут видеть друг друга в очереди только если открыли одну и ту же развёрнутую онлайн-версию сервера.
- Онлайн-дуэль в этой сборке — отдельный сетевой режим с очередностью ходов; существующий автобой игры пока остаётся отдельным режимом.
- Это MVP. Перед крупным публичным запуском рекомендуется добавить лимиты запросов, подтверждение email, восстановление пароля, модерацию и резервные копии базы.
- Не используй один и тот же пароль на разных сайтах.
